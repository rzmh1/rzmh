## التشغيل لأول مرة

المتطلبات: Node.js 24 أو أحدث، وFFmpeg وFFprobe لمعالجة الفيديو وقياس مدته. كلاهما متوفر في Dockerfile المرفق.

```bash
npm ci
npm run setup
npm run setup:admin
npm start
```

افتح `http://localhost:3000`. الدخول من `/#/login`، والإدارة من `/#/admin` بحساب المالك الذي أنشأته. التسجيل العام ينشئ طالبًا، ولا توجد كلمة مرور افتراضية.

`setup` ينشئ ملف `.env` خاصًا ومفتاح تشفير عشوائيًا عند غياب الملف فقط. لا تشارك هذا الملف أو تضفه إلى المستودع.

## تحديث استضافة قائمة

احتفظ بملف `.env` و`APP_KEY` ومجلد `DATA_DIR` والوسائط. لا تستبدل قاعدة بياناتك بقاعدة جديدة. اتبع [دليل الترقية الآمنة](docs/UPGRADE-3.md) قبل تحديث الملفات. أول تشغيل ينشئ نسخة متسقة من قاعدة ما قبل الترقية، ثم يضيف جداول التعلم وحقول مدة الفيديو دون إعادة إنشاء الحسابات أو الاشتراكات.

## رحلة الطالب

- الزائر يستعرض المتجر، ثم يسجل حسابًا مجانيًا لمشاهدة معاينة الدورة المحددة. يعود بعد الدخول إلى الدورة أو مراجعة الاشتراك التي اختارها.
- بعد دفع Live مؤكد من الخادم وتفعيل الاشتراك ← رحلة الطالب الترحيبية لمن لم يكملها، ثم الأدوات والخطط الحالية. التسجيل المجاني لا ينقل الزائر تلقائيًا إلى لوحة الطالب.
- اختيار الاختبار والمسارات والدورات والمدرسين، مع حرية اختيار مصدر مختلف لكل مرحلة.
- `/#/journey`: «خطتي وتقدمي»، مهام اليوم، إنجاز الأسبوع، مدد المحتوى، المهام الإضافية، الدورات والوقت المسجل.
- `/#/learning-settings`: تعديل الوقت والأيام والموعد، وإعادة توزيع المتبقي.
- المشاهدة والقراءة منفصلتان عن دقة الإجابات في الاختبارات. لا تُنشأ درجة إتقان من إكمال فيديو.
- `/#/instructors`: مصادر منشورة من قاعدة البيانات، دون أسماء مدرسين مثبتة داخل الكود.
- `/#/discover`: نقطة البداية والاختبارات التشخيصية المنشورة؛ لا تظهر نتيجة تشخيصية إن لم يوجد اختبار فعلي.

المدد المجهولة لا تُخمَّن. القراءة والحل والمراجعة والراحة تحمل تقديرات واضحة. إذا لم يتسع الوقت للمحتوى، تظهر المهام المتبقية والتنبيه بدل تجاوز الوقت اليومي.

## الإدارة

راجع [دليل إدارة المدرسين والدورات والخطط](docs/LEARNING-ADMIN-GUIDE.md): إضافة المصادر والمسارات، ربط الدورات بالمراحل، رفع الفيديو وقياسه، الأسئلة والاختبارات، التحديثات اليومية والأسبوعية، قواعد الجدولة، وتقدم الطلاب.

استمرت أيضًا إدارة الاشتراكات والتمديد اليدوي والوسائط، ومحررات HTML/CSS/JavaScript المعزولة، وإعدادات الدفع وAI والنسخ وسجل الأحداث. حفظ المحتوى مشترك لكل المستخدمين، مع كشف تعارض تعديل أحدث من جلسة أخرى.

## الأسعار

شهر **19.99**، 3 أشهر **39.99**، 6 أشهر **59.99**، سنة **99.99** ريال. جميع المدد تشمل المسارات نفسها؛ STEP عند إطلاق محتواه. السعر يحدده الخادم، ولا يوجد تجديد تلقائي. التوفير السنوي مقابل 12 شهرًا منفردًا هو 139.89 ريال، نحو 58.3٪.

## الاستضافة والربط

- [النشر وHTTPS والقرص الدائم والنسخ](docs/DEPLOYMENT.md).
- [ربط S3/R2 وStripe وOpenAI](docs/INTEGRATIONS.md).
- [تقرير هذه المرحلة والاختبارات والحدود](docs/LEARNING-PLATFORM-REPORT.md).

موصل الدفع الفعلي المتوفر هو Stripe Checkout. وضع الرابط الخارجي لا يؤكد الدفع ولا يفعّل الاشتراك تلقائيًا. الذكاء الاصطناعي يستخدم OpenAI Responses من الخادم؛ يمكنه الاطلاع على بيانات الرحلة التعليمية عند موافقة الطالب من الإعدادات فقط. الدفع وAI يحتاجان مفاتيح حسابك واختبار اتصال فعلي؛ لا تتضمن الحزمة مفاتيح أو ادعاء اتصال ناجح بمزود خارجي.

للتخزين السحابي استخدم حاوية S3/R2 خاصة. وضع `local` يعمل على القرص الدائم. الملفات خارج SQLite، والوصول المدفوع يمر بفحص صلاحيات الخادم وروابط قصيرة الصلاحية.

## البناء والتحقق

```bash
npm run build
npm run check
npx playwright install chromium
npm run test:browser
```

ملف محرر CodeMirror المجمع موجود في `dist/assets/editor.bundle.js`. يمكن تشغيل الحزمة على الخادم باستخدام `npm ci --omit=dev` دون إعادة بناء المحرر. الخط العربي مستضاف محليًا؛ الرخصة في `FONT-LICENSE.txt`.

اجتازت النسخة 29 اختبارًا آليًا و5 اختبارات Chromium بواجهة فعلية، تشمل HTTP وSQLite مؤقتة والجدولة وFFmpeg/FFprobe وRTL بعرضي 1440 و390 بكسل. اختبارات Stripe وOpenAI تستخدم استجابات آلية محاكية، وS3 اختبار توقيع محلي. اختُبر تشغيل Docker واستمرار البيانات بعد إعادة التشغيل. ما زال فحص Safari/iPhone والأجهزة الفعلية والخدمات الخارجية وبيئة Northflank الفعلية مطلوبًا قبل الاعتماد.

## الملفات الرئيسية

```text
server/                       الخادم والحسابات والبيانات والتكاملات
server/learning*.mjs           ملفات التعلم والترحيل والصلاحيات والتحقق
server/scheduler.mjs           الجدولة حسب المدد والوقت والنتائج الفعلية
dist/                        مكونات الواجهة الأصلية المطورة
client/                       مصدر محررات الأكواد وتصدير مراجعة الواجهة
scripts/                      الإعداد والنسخ والبناء
tests/                       اختبارات الواجهة والخادم والوسائط والجدولة
docs/                        الإدارة والتشغيل والترقية والتقارير
Dockerfile + compose.yaml      تشغيل Node.js 24 مع FFmpeg وقرص دائم
.env.example                  أسماء الإعدادات دون أسرار
```

بيانات التعلم محفوظة على الخادم؛ LocalStorage المتبقي لتفضيل الثيم ومسودة الزائر. لا تحتوي حزمة التسليم على قاعدة الطلاب أو الوسائط أو أسرار الاستضافة. التقارير الأقدم داخل `docs` توثّق مراحل سابقة، وتقرير المتجر 3.1 هو مرجع التغييرات الأخيرة، وتقرير التعلم 3.0 يشرح وظائف الطالب المحفوظة.
