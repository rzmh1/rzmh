# إعادة تصميم الواجهة

- المتجر: أقسام «الكمي واللفظي» و«التأسيس والتدريب» و«التحديثات» و«طريقة البدء» مخفية افتراضيًا (تُظهر من «إدارة واجهة المتجر»). استُبدلت بطاقات أدوات الطالب بأربع بطاقات فوائد، وأُضيفت بطاقة ختامية.
- منصة الطالب: غلاف مستقل (`dist/student-shell.js`, `dist/student-app.css`) بشريط علوي وقائمة جانبية وشريط سفلي للجوال، بلا قائمة المتجر وتذييله. صفحة «اليوم» أُعيد بناؤها في `learning.js`.
- حُدّثت اختبارات `storefront.test.mjs` و`storefront-final.test.mjs` لتطابق ذلك. لم تُشغَّل اختبارات المشروع في بيئة العمل (تحتاج `npm ci` وNode 24)، فشغّل `npm run check`.
