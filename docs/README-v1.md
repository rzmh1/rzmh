# رُزمة — نموذج أولي قابل للتشغيل

واجهة متجر عربية RTL للاستعداد للقدرات والتحصيلي، مع مسار STEP قادم. هوية بنفسجية وكريمية وكحلية، رسم أصلي لرُزمة كتب، خط IBM Plex Sans Arabic مستضاف محليًا، ووضع ليلي ونهاري.

## أسرع طريقة للمقارنة

افتح ملف `preview.html` مباشرة بالنقر عليه. يحتوي على نسخة مجمّعة مستقلة من النموذج، بما فيها الخطوط. للتطوير استخدم الملفات المنظمة وخادم التشغيل أدناه. تتضمن النسخة نفس تنبيه الوظائف التجريبية.

## التشغيل

المتطلب: Node.js 20 أو أحدث. لا تحتاج تثبيت حزم أو ملف أسرار.

```bash
cd /workspace/sites/ruzmah
npm run dev
```

افتح http://localhost:3000 في المتصفح. من جهازك بعد فك ملف المشروع، ادخل إلى مجلد `ruzmah` ثم نفّذ الأمر نفسه. يمكن تغيير المنفذ:

```bash
PORT=3001 npm run dev
```

لا تفتح index.html ببروتوكول `file://` لأن المشروع يستخدم وحدات ES Modules. يمكن نشر مجلد `dist` على أي استضافة ثابتة؛ الروابط تستخدم hash routing ولا تحتاج إعداد rewrite.

## الفحص

```bash
npm run check
npm run build
```

لا توجد مرحلة تجميع؛ `dist` هو المصدر القابل للتشغيل نفسه. أمر build ينفذ الفحوص. تفحص الاختبارات سلامة البيانات والتوفير والتصحيح والأسئلة الخاطئة وتوليد الصفحات والمسارات والملفات المحلية. اجتازت ٣٣ حالة عرض، وفُحصت صياغة وحدات JavaScript. لا تعادل هذه الفحوص اختبار متصفح حقيقي؛ لم تتوفر أداة المتصفح في جلسة الإنشاء، وبالتالي لم تُجر معاينة بصرية للجوال أو الكمبيوتر.

## ما يعمل الآن

- قائمة أقسام منسدلة، قائمة جوال، وضع ليلي محفوظ، وتنقل كامل بين الصفحات.
- ٣ دورات توضيحية، كل منها بدرس نصي مجاني ومثال وسؤال. لا توجد فيديوهات أو تقييمات أو أعداد طلاب مختلقة.
- بنك أسئلة قابل للبحث والتصفية حسب القسم والمادة، وتصحيح مع الشرح.
- اختبار توضيحي من أسئلة البنك، بمؤقت ٣ دقائق وإجابات قابلة للتغيير قبل الإنهاء. يُحسب الزمن من موعد النهاية حتى عند الانتقال بين الصفحات. تُحفظ الإجابات، والأسئلة الخاطئة والنتائج الفعلية.
- دفتر أخطاء، إعادة المحاولة، إزالة السؤال بعد إتقانه، خطة مهام، إكمال الدروس ومتابعة التقدم.
- مسودة تدعم لمسًا وقلمًا وماوسًا، لونًا وسُمكًا، التراجع، المسح، وتنزيل PNG. تُحفظ الخطوط محليًا وتتأقلم مع تغيير حجم المساحة.
- المدرس الذكي يعرض إجابات ثابتة بوضوح، وقراءة حسابية بسيطة لعدد الأخطاء، دون إرسال بيانات أو استخدام API.
- الأسعار: 19.99 / 39.99 / 59.99 / 99.99 ريال. التوفير محسوب من سعر الشهر الحالي؛ السنوي يوفر 139.89 ريال (حوالي 58٪) مقابل 12 شهرًا بالسعر الشهري الأصلي. كل المدد تشمل المميزات نفسها.
- اختيار مدة وحفظها كتفضيل فقط، دون دفع أو تفعيل أو تجديد تلقائي.

## إدارة المحتوى دون تعديل الكود

افتح `#/admin`. التغييرات محلية لهذا المتصفح:

- إضافة وتعديل وحذف الأقسام والأقسام الفرعية، إظهارها وإخفاؤها وترتيبها.
- إدارة الدورات وترتيبها وصورها وحالتها، وتحديد مجاني/مدفوع كبيانات تمهيدية.
- إضافة دروس نصية وأمثلة وربط أسئلة ورابط فيديو 720p. أول درس يبقى مجانيًا. لم يُبنَ رفع سحابي أو تحويل جودة بعد.
- إدارة الأسئلة وخياراتها والإجابة الصحيحة وشرحها. الاختبار التوضيحي يستخدم بنك الأسئلة الحالي.
- نشر تحديثات وتجميعات وتاريخ تعديل فعلي. عند غيابها يظهر متجر بحالة فارغة.
- تغيير عنوان ووصف الرئيسية وصورتها والشعار ولون الهوية.
- تعديل أسماء مدد الباقات وأسعارها؛ المدد الأساسية ثابتة لتبقى باقة شاملة واحدة.
- حفظ مراجع ملفات بروابط. الطلاب والاشتراكات واجهة فارغة تمهيدية للخادم.
- تصدير واستيراد المحتوى JSON مع تحقق من البنية، أو استعادة نسخة النموذج الأصلية.

صدّر نسخة احتياطية قبل الاستيراد؛ الاستيراد يستبدل المحتوى المحلي. تعديلات الأدمن لا تنتقل إلى متصفح آخر أو إلى مصدر المشروع تلقائيًا. المصدر الافتراضي في `dist/data.js`. لنسخة نشر بمحتواك، تُنقل نسخة JSON إلى طبقة مستودع بيانات لاحقًا، أو تُحدّث البيانات الافتراضية عند تجهيز إصدار جديد.

## حدود يجب معرفتها

هذا نموذج واجهة، وليس منصة جاهزة تجاريًا. التسجيل لا يكوّن حسابًا حقيقيًا؛ يطلب اسم عرض وموافقة على التجربة فقط، ولا يطلب كلمات مرور. لوحة الأدمن متاحة للتجربة بلا صلاحيات ولا حماية إنتاجية. لا تحفظ بيانات طلاب حقيقية فيها. الوصول المدفوع لا يُفرض في هذا النموذج.

لم تُربط: قاعدة بيانات مشتركة، مصادقة أو استعادة كلمة مرور، صلاحيات أدمن، رفع وتشفير ومعالجة فيديو، إدارة ملفات سحابية، اختبارات رسمية، بوابة دفع أو فواتير أو ضرائب، اشتراكات فعلية، ذكاء اصطناعي، بريد دعم أو إشعارات. لا توجد مشاهدة دون إنترنت أو خدمة عامل لتخزين الفيديو.

المحتوى الافتراضي توضيحي ويمكن مراجعته وتعديله. الأرقام التعليمية لا تمثل التنبؤ بدرجة الاختبار. اسم الدعم الرسمي وحدود استخدام المدرس تُضاف عند الإطلاق.

## تنظيم الملفات

```text
ruzmah/
  dist/
    index.html       # المدخل، RTL، وبيانات الصفحة
    styles.css       # الهوية والاستجابة والوضع الليلي
    app.js           # التنقل وربط التفاعلات
    ui.js            # مكونات العرض المشتركة
    pages.js         # المتجر وصفحات الطالب
    data.js          # بيانات منظمة وتخزين محلي والتحقق من الاستيراد
    model.js         # منطق التدريب وتصحيح الاختبارات
    drawing.js       # الرسم وحفظ المسودة
    admin.js         # إدارة المحتوى المحلية
    assets/          # الخطوط والشعار الرمزي
  scripts/
    serve.mjs        # خادم تطوير بلا اعتماديات
    check.mjs        # فحوص النموذج
  .openai/hosting.json
  FONT-LICENSE.txt
  package.json
```

اخترت JavaScript بوحدات ES وCSS دون إطار لأن نطاق هذه المرحلة تفاعلات محلية بلا خادم، وبذلك يعمل المشروع دون تثبيت اعتماديات. المكونات والبيانات ومنطق التصحيح منفصلة لتسهيل نقلها إلى Next.js/TypeScript عند بدء بناء المنتج الفعلي.

## التوسع لاحقًا

تحوّل `data.js` إلى طبقة مستودع typed repository تتصل بقاعدة البيانات؛ العلاقات الأساسية هي `sectionId` في الدورات والأسئلة، و`questionId` في الدروس. تفصل خدمة الحسابات عن المحتوى، وتُفرض صلاحيات الاشتراك على الخادم. تُرفع الأصول إلى تخزين مخصص، وتتحقق دفعات الاشتراك عبر webhooks موثوقة. مفاتيح الدفع والذكاء الاصطناعي تبقى في أسرار الخادم. لا يلزم أي مفتاح في هذا النموذج.

مفاتيح التخزين المحلية: `ruzmah-content-v1`, `ruzmah-student-v1`, `ruzmah-drawing-v1`, `ruzmah-quiz-v1`, `ruzmah-theme`. يمكن حذفها من إعدادات المتصفح لإعادة التجربة. تصدير الإدارة يشمل المحتوى فقط، ولا يشمل اسم الطالب أو التقدم أو المسودة.

الخط IBM Plex Sans Arabic مرخص وفق SIL Open Font License 1.1. نص الرخصة في `FONT-LICENSE.txt`. الرسم الرئيسي وصور الدورات منشأة باستخدام HTML/CSS داخل المشروع.

## إعادة توليد ملف المقارنة بعد التعديلات

ملف `preview.html` نسخة مجمّعة؛ عدّل المصدر في `dist` أولًا. لإعادة توليده، يمكن استخدام esbuild كأداة مؤقتة (يتطلب شبكة في أول مرة، ولا يضيف اعتماديات للتشغيل):

```bash
npm exec --yes --package esbuild@0.25.12 -- esbuild dist/app.js --bundle --format=iife --outfile=.preview-bundle.js
node scripts/export-preview.mjs .preview-bundle.js
```
