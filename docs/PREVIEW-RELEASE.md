# معاينة Premium Paper

الرئيسية تحول إلى /preview/، ولوحة الإدارة التجريبية /preview/#/admin والطالب /preview/#/dashboard بدون حساب. البيانات والإضافات والملفات في المعاينة محلية على الجهاز؛ لا تستدعي بيانات الإنتاج ولا تمنح صلاحية حقيقية.

النسخة المتصلة محفوظة في /platform.html#/ بكل وحداتها ومسارات API وقاعدة بياناتها ووسائطها. لم تُحذف ملفات الخادم أو تعدل إعدادات الاستضافة أو البيانات أو المفاتيح. التصميم الجديد معاينة، ولم يُربط بمنطق الحسابات القديم بعد.

التنزيل في المعاينة يحفظ PDF/MP4 والصور المختارة محليًا مع فحص النوع والحجم. لم يتم إثبات تنزيل الوسائط الحقيقية من استضافة المالك أو اختبار iOS/Android. الدفع وAI لا يدعيان العمل في المعاينة. اختبارات النسخة المعزولة 25 اختبارًا؛ اختبارات المشروع القديم تبقى مطلوبة بعد الدمج.
