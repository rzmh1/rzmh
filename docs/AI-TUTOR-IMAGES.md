# الصور في المدرّس الذكي

أضيف إرفاق الصور التعليمية في صفحة المدرّس الذكي.

## ما يدعمه الإصدار الحالي

- صور JPG وPNG وWebP، أو ملف PDF واحد لكل رسالة.
- الحد الأقصى للصورة الواحدة 4 ميجابايت، وملف PDF 5 ميجابايت.
- يتحقق الخادم من MIME ومن توقيع الملف الفعلي، ولا يعتمد على اسم الامتداد وحده.
- يرسل PDF عبر Responses API كملف، بما يسمح بتحليل النصوص وصور الصفحات والرسومات؛ ملفات Word والجداول غير مدعومة في هذه الواجهة حاليًا.
- تُرسل الصورة مباشرة إلى Responses API من الخادم؛ لا يظهر مفتاح OpenAI في المتصفح.
- لا تُحفظ بايتات الصورة داخل سجل المحادثة أو قاعدة بيانات رُزمة؛ يُحفظ نص السؤال واسم المرفق فقط.
- تُرسل المرفقات إلى OpenAI لمعالجتها؛ خيار `store: false` يمنع تخزين استجابة Responses كحالة محادثة لدى API، لكنه لا يلغي سياسات الاحتفاظ الأمنية أو المعالجة لدى المزود. راجع إعدادات بيانات حساب OpenAI قبل استخدام صور الطلاب.
- يطلب المدرّس استخراج السؤال والخيارات الظاهرة وشرح الإجابة، والتنبيه عند عدم وضوح النص أو الرسم.

## المكتبة الدائمة لمصادر المدرّس الذكي

توجد واجهة مستقلة في لوحة المالك باسم **مصادر المدرس الذكي**:

- يمكن رفع عدة ملفات دفعة واحدة، أو إضافة ملفات سبق رفعها إلى مكتبة ملفات رُزمة.
- تُحفظ النسخة الأصلية في تخزين رُزمة، وتُرسل نسخة إلى OpenAI Files API ثم تُربط بمكتبة Vector Store دائمة.
- عند سؤال الطالب، يضيف الخادم أداة file_search إلى Responses API؛ يبحث النموذج في المقاطع ذات الصلة فقط بدل إرسال كل الملفات مع كل رسالة.
- يدعم فهرس File Search: PDF وDOC وDOCX وPPTX وTXT وMD وHTML وJSON وملفات برمجية محددة مثل JS وPY وCSS وTS.
- الحد الأقصى لدى OpenAI هو 512 MB للملف الواحد، وليس حدًا إجماليًا ثابتًا نحدده للطالب. سعة المشروع لدى Files API تصل إلى 2.5 TB، وتظل حدود الخطة والاستضافة والتخزين الفعلية واجبة المراجعة.
- لا يصبح الملف متاحًا للمدرس إلا بعد اكتمال الفهرسة. تعرض لوحة المالك حالة كل ملف، وتسمح بإعادة الفهرسة أو إزالته من المكتبة.
- إزالة الملف من فهرس المدرس لا تحذف النسخة الأصلية من تخزين رُزمة. يجب إزالة الملف من المكتبة أولًا قبل حذفه من التخزين.
- تظهر أسماء الملفات التي استند إليها المدرس في نهاية الإجابة عندما ترجع أداة البحث استشهادات.

### التكلفة والاحتفاظ

- أول 1 GB من مساحة Vector Store مجانية إجمالًا؛ بعد ذلك تبلغ كلفة التخزين المنشورة $0.10 لكل GB يوميًا. تُحسب المساحة من الأجزاء المفهرسة والـ embeddings، وقد تختلف عن حجم الملف الأصلي.
- تخزين الملفات الدائم في OpenAI مقصود في هذه الميزة؛ store=false يخص حالة استجابة Responses ولا يحذف الملفات أو الفهرس.
- راجع سياسات بيانات مشروع OpenAI وإعدادات الاحتفاظ قبل رفع مواد الطلاب أو الملفات التي تحتوي معلومات شخصية.

المراجع الرسمية:

- [Retrieval — تخزين Vector Stores والتسعير](https://developers.openai.com/api/docs/guides/retrieval)

## حدود الإصدار

- ملفات الجداول مثل XLSX وCSV ليست ضمن صيغ File Search المعتمدة في المكتبة الحالية؛ حوّلها إلى PDF أو TXT بعد مراجعة المحتوى أو استخدم مسار تحليل مخصص لها.
- الصورة ليست ضمانًا لصحة قراءة السؤال؛ راجع الأرقام والرموز والرسومات، خصوصًا الصور منخفضة الجودة.
- لا ترفع صورًا شخصية أو مستندات هوية أو معلومات حساسة.
- استهلاك الصور والبحث في الملفات قد يزيد تكلفة طلبات OpenAI؛ يظل الحد اليومي وحد الطلبات على الخادم مطبقًا.
- لا تُستخدم هذه الميزة لنسخ بنك أسئلة أو صور محمية من مصدر لا تملك حق إعادة استخدامها. عند بناء محتوى جديد، استخدم وصف المهارة وصياغة تدريبية أصلية ورسومًا جديدة، وراجعها قبل نشرها للطلاب.
